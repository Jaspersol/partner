# 定时

**简体中文** | [繁體中文](./schedules.zh-TW.md) | [English](./schedules.en.md)

返回 [文档目录](./README.md)。

一条任务 = 一句话 + 一个触发规则。到点时这句话作为“调度”来源进入队列，和打字、语音排在一起，按顺序执行。

## 规则

| 类型 | 写法 | 说明 |
|---|---|---|
| `cron` | 五段 cron | 按本机时区 |
| `interval` | 分钟数，≥ 1 | 从创建那一刻起算 |
| `once` | 一个时间点 | 必须晚于现在，执行后标为已执行 |

限制：内容不超过 2000 字，间隔 1 分钟到 1 年，最多 100 个任务。

## 在页面上管理

侧边栏 **定时** 页：

- 新建：选规则，填内容。日期时间选择器带“1 小时后 / 明天 9:00 / 下周一 9:00”快捷项，过去的时间不可选。
- 暂停 / 恢复：恢复时跳过暂停期间错过的时间点，不补发。应用没开时错过的也同样跳过。
- 删除。

没有“编辑”。要改规则或内容，删了重建，这样旧的发放记录不会吞掉新的触发。

## 让助手自己建

主 agent 始终有 `schedule_create`、`schedule_list`、`schedule_delete` 三个工具（子 agent 没有）。

- 工具结果里会带“现在是几点”，一次性任务可以直接写“几分钟后”。
- 审批跟随输入区的挡位：“危险指令审批”只问删除；“全部审批”创建和删除都问；列出永远不问。
- 原因：任务内容到点会被当成你发的消息，不能让助手读到的网页替你悄悄留一条。

## 存储

`<workspace>/scheduler/tasks.jsonl` 和 `receipts.jsonl`，只追加写入。
