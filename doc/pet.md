# 桌宠

**简体中文** | [繁體中文](./pet.zh-TW.md) | [English](./pet.en.md)

返回 [文档目录](./README.md)。

一个常驻桌面的 Live2D 角色：它不参与对话，只读取同一条会话日志里**已经定稿**的助手回复，按关键词判断情绪，再用固定场景表播动作和表情。不改系统提示词，不要求模型输出情绪标签，也不新增任何模型请求。

## 1. 它是什么

- **一个独立的小窗口**：透明、无边框、置顶、不进任务栏、不能缩放。默认 300×360，模型加载后按模型画布尺寸 × 缩放比例自动调整。
- **只读会话**：每 1 秒（说话时每 250 ms）轮询 `GET /api/pet/feed`，拿到 `seq` 之后的新回复。历史回复不会补演，所以刚打开桌宠时它不会一连串地演过去。
- **积压与游标**：feed 单次遍历游标之后的积压，只返回最后五条已定稿回复；游标推进到请求开始时的最新序号，即使没有回复也会前进。文件会话日志使用可在打开时重建的内存稀疏索引定位范围，删除历史后重建，不删除用户历史来加速读取。
- **不看流式内容**：只有助手已经定稿的回复参与匹配，正在流式输出的那半句不算。
- **和你共用设置**：缩放、待机间隔、睡眠时间、问候时间、情绪冷却、表情保持、动作映射、关键词字典都在「设置 → 桌宠」里；保存后桌宠窗口热更新，不用重启。
- **窗口操作失败**：如果设置已保存但桌宠窗口开关失败，桌宠设置页显示原因和重试按钮，开关显示当前窗口状态；重置位置失败也会在本页显示。
- **不做的事**：不弹气泡、不搭话、不发送任何请求给模型。

## 2. 装 Cubism Core

Core 是 Live2D 的运行时，需要你从 Live2D 官网自己下载并同意其协议。

只认 **Cubism 5 SDK for Web R5**，文件名为 `CubismSdkForWeb-5-r.5.zip`。旧版 Core 与 easy-live2d 1.x 不兼容，所以导入时严格校验：

| 检查项 | 要求 |
|---|---|
| 整包 SHA-256 | `67064a7fb1812cf502f5c4a03bfe12cc638c75a621bb4acf06bb28763df06ba0` |
| 取出的文件 | 压缩包里以 `/Core/live2dcubismcore.min.js` 和 `/Core/LICENSE.md` 结尾的两个条目 |

SDK 顶层目录名不固定，按条目后缀匹配，不按完整路径。哈希不符直接拒绝，防止旧版 Core 或改过的脚本进入页面的 `script-src`。

1. 在「设置 → 桌宠 → Cubism Core」里点官网下载链接，自行下载 R5 的 zip。
2. 勾选「我已从 Live2D 官网下载并同意其协议」，否则导入按钮不可用。
3. 填 zip 的绝对路径，点「导入」。
4. 成功后页面显示「已安装 R5」和哈希前 8 位。

文件落在 `%LOCALAPPDATA%\Partner\pet\core\`，模型落在 `%LOCALAPPDATA%\Partner\pet\models\<id>\`。模型 id 是目录名的 ASCII 化基名加文件内容哈希的前 8 位，所以同一份模型重复导入不会产生第二份。

## 3. 导入模型

模型**不随应用分发**，版权属于各自的作者。你可以导入目录，也可以导入 zip。

- **路径**：目录或 zip 都可以；zip 里的中文文件名没有设 UTF-8 标志时按 GBK 解码，所以老包也能读。
- **多个 model3**：一个包里有不止一个 `*.model3.json` 时，页面会列出候选（相对路径），让你挑一个；只有一个时直接导入。
- **只复制被引用的文件**：`model3.json` 的 `FileReferences` 里列出的 moc3、纹理、物理、姿态、表情、动作和音效才复制，同一目录下没被引用的贴图和 `exp_*.json` 不会跟着进来。
- **校验**：路径必须是相对路径、不能含 `..`、规范化后要落在模型根目录内、不能是符号链接或 junction；扩展名只允许 `.json .moc3 .png .jpg .webp .wav .mp3 .ogg .flac`（不接收 `.js`）；总量 200 MB、文件数 2000 为上限。
- **重复导入**：内容没变就返回已有的那一条，不占第二份空间。
- 「已导入」列表显示名称（目录名）、动作数、表情数、有无点击区域、占用大小；可以设为当前、删除，也可以删除当前模型（删除后桌宠不显示，直到再选一个）。

模型没有 `HitAreas` 时，头部和面部的点击分区按模型包围盒的纵向比例切分，比例在「动作映射」页签里用滑块调。

窗口会裁到人物本身的不透明范围，而不是整张模型画布。模型的画布通常留了很大空白（实测一个模型的人物只占画布的 44%×47%），直接照画布开窗会让桌宠看起来很小，按画布高度算的分区比例也会落在空白上。所以加载后渲染一帧、读回 alpha 通道量出人物的盒子，窗口就按这个盒子开，`100%` 指的是人物 360 逻辑像素高。

## 4. 场景

场景是固定的，触发只有两类：本地交互 / 计时，以及回复文本的关键词匹配。每个场景由「动作组合 + 表情」组成，动作先按当前模型的映射表解析，映射不到就退到程序化参数轨道，参数也不存在就跳过。

「程序化动作调校」可为每个模型手动将标准通道映射到实际参数 ID；模型的 cdi3 参数名只作为候选，不自动猜测，也不能证明参数在运行时存在。模型倍率和每动作倍率默认均为 1，范围 -4 至 4，负值反向，两者相乘；模型 motion 仍优先。可给动作添加实际参数 ID 的偏移轨道：首尾必须为零，时间严格递增，末帧为动作时长，最终值受模型参数范围限制。保存并打开桌宠后，读取动作诊断可查看已加载配置解析为 motion、程序化或跳过，以及实际参数范围和缺失 ID；诊断是静态解析候选，motion 仍可能被优先级拒绝并回退。诊断和预览不包含未保存的编辑。自动位移校准未实施。

| 场景 | 触发条件 | 动作组合 / 表情 | 优先级 |
|---|---|---|---|
| 首次加载 | 模型就绪之后 | 打招呼 + 眨眼 / 笑 | 2 |
| 静默 | 没有其他场景运行 | 常驻微动作 / 默认 | 0 |
| 待机 | 静默持续 `rand(IdleMin, IdleMax)` 秒 | 打招呼 45%、伸懒腰 45%、眨眼 10% → 回到静默 | 1 |
| 点击头部 | 单击，落在头部 | 模型自带 `TapHead`/`Tap` 组时优先播它；否则三选一：摸头反应 / 歪头 / 左右晃动头部。表情二选一：害羞 / 怒 | 4 |
| 点击面部 | 单击，落在面部 | 模型自带 `TapFace`/`TapHead`/`Tap` 时优先播它；否则眨眼 + 轻微后仰。表情：笑或害羞 | 4 |
| 点击身体 | 单击，落在身体 | 模型自带 `TapBody`/`Tap` 时优先播它；否则左右晃动身体或缩身。表情：害羞或怒 | 4 |
| 鼠标悬停 | 悬停 600 ms | 视线跟随常开；本场景只加一次轻微歪头 / 默认 | 叠加层 |
| 拖拽模型 | 拖动开始 | 拖动回弹（随速度）/ 默认；速度过阈值改为惊讶 | 5 |
| 快速拖拽后松开 | 松开速度超过阈值 | 左右晃动头部 + 左右晃动身体 + 回弹 / 惊讶 | 5 |
| 双击模型 | 双击 | 打招呼 + 挥手 / 笑 | 4 |
| 语音或 TTS | 正在朗读或说话 | 口型同步 + 每 3–5 s 轻微点头 / 当前情绪表情或笑 | 叠加层 |
| 定时问候 | 本地时间到问候时间之一（每天每项一次；睡眠中先唤醒） | 打招呼 + 挥手 / 笑 | 2 |
| 空闲超时 | 无交互、无新回复达 `SleepAfterMinutes` | 伸懒腰 → 睡眠 / 默认或困 | 1 |
| 睡眠中点击 | 睡眠状态下的任意点击 | 先唤醒（眨眼 + 睁眼），再播该点击本身的场景 | 4 |
| 情绪：笑 / 怒 / 哭 / 害羞 | 回复匹配结果，或设置页的预览按钮 | 挥手或点头 / 鼓脸 / 抽泣 / 歪头或缩身；表情对应 | 3 |

规则细节：

- 新场景的优先级要 **≥** 当前主场景才能抢占，否则丢弃；情绪场景例外，会排队一条，等当前场景结束再执行。
- 情绪场景有冷却（`EmotionCooldownSeconds`）；同一情绪连续触发只刷新表情保持时间，不重播动作。
- 睡眠中只有点击能唤醒；唤醒先播唤醒场景，再播这次点击自己的场景（第一次点击不会「没反应」）。新回复和定时问候会先唤醒再执行原场景；拖拽照常执行但不唤醒。
- 睡眠中只有眼球跟随光标，头部不动，说话时也不点头——睡姿由 `sleep` 轨道保持，别的写入会和它打架。
- 视线跟随时头部最多转到参数量程半宽的 40%（±30° 的参数即 ±12°），眼球跟满；光标在窗口外时按离窗口的距离衰减，离开一个窗口宽度就不再看。有程序化轨道或模型 motion 驱动头部时，视线的头部分量降到 20%，结束后 0.3 s 内恢复。
- 程序化轨道、视线和拖动回弹都是叠加在模型自身 motion、眨眼、呼吸之上的偏移，在物理计算之前写入，所以头发和物理平滑链会跟着动；为此给 easy-live2d 1.1.0 打了补丁（`ui/patches/easy-live2d+1.1.0.patch`，`npm install` 时由 patch-package 应用）。
- 睡眠状态目前不会降低呼吸频率。easy-live2d 1.1.0 在 effects 内部以帧间隔更新 Framework 的 `CubismBreath`，现有物理前钩子只能看到叠加后的参数，无法安全地单独调速；避免通过缩放合成参数影响 motion 或物理。
- 表情在 `ExpressionHoldSeconds` 后回到默认。
- 待机、问候、冷却的随机源和时钟都是注入的，所以测试能固定它们。

## 5. 情绪关键词字典

「设置 → 桌宠 → 情绪字典」里四种情绪各有一张可编辑表，另有否定前缀、最低权重和「恢复默认」。同一个 `emotion.ts` 既给桌宠打分，也给页签里的试算框打分，所以试算结果就是真实结果。

匹配规则：

1. 预处理：去掉代码块、行内代码、URL 和 Markdown 链接目标；英文转小写；最多取 4000 字。
2. 关键词按长度降序查找，已被更长关键词占用的区间不再重复计算——所以「不开心」不会同时命中「开心」。英文要求单词边界，中文和 emoji 按子串匹配。
3. 命中位置前 2 个字符内出现否定前缀（`不 没 别 不太 并不 not no never`），且「否定词 + 关键词」本身不在字典里时，这次命中作废。
4. 每种情绪取**命中关键词里的最高权重**作为主分，主分最高的情绪胜出；主分相同比该情绪命中权重总和；仍相同取最后出现位置更靠后的那个。
5. 主分低于 `MinWeight` 或者没有命中，就不触发。

默认字典（权重 1–5；可在页签里增删改）：

| 情绪 | 关键词（权重） |
|---|---|
| 笑 | 哈哈(3) 嘻嘻(3) 好笑(3) 开心(3) 高兴(3) 太好了(4) 恭喜(4) 棒(2) 不错(1) 喜欢(2) 有趣(2) 😄(4) 😊(3) 🎉(4) haha(3) great(2) awesome(3) glad(2) |
| 怒 | 生气(4) 气死(5) 可恶(4) 讨厌(3) 烦(2) 不能接受(3) 过分(3) 哼(3) 😠(4) 😡(5) angry(4) annoying(3) |
| 哭 | 难过(4) 伤心(4) 哭(4) 呜呜(4) 抱歉(2) 遗憾(3) 可惜(2) 不开心(3) 失败(2) 😢(4) 😭(5) sorry(2) sad(4) unfortunately(2) |
| 害羞 | 害羞(4) 不好意思(3) 脸红(4) 过奖(3) 哪里哪里(3) 被夸(3) 讨厌啦(4) ///(3) 😳(4) ☺️(3) blush(4) flattered(3) |

`讨厌啦`（害羞）比 `讨厌`（怒）长，按最长匹配优先，所以不会被算成怒。

例：「哈哈，这个太好笑了，不过被你夸得有点害羞」→ 笑 {哈哈 3, 好笑 3}，主分 3；害羞 {害羞 4}，主分 4 → 触发「情绪：害羞」。

## 7. 已知限制

- **口型没有音频**：TTS 在 .NET 侧用 NAudio 播放，WebView 拿不到音频流，所以口型是「说话时按 6–9 Hz 的随机包络张合」，不是真实音素。`speaking` 由后端按播放状态上报，只能说明在说话，不能说明说到哪个字。
- **动作靠程序化兜底**：不能假设模型自带需要的动作和点击区域。示例模型只带两个动作组、没有 `Idle` 组、没有 `HitAreas`、物理和姿态也没有，所以很多场景落到参数关键帧上（`ParamAngleX/Y/Z`、`ParamBodyAngle*`、`ParamEye*`、`ParamMouthForm` 等）。模型没有那个参数就跳过这一段，不会报错也不会硬插。动作映射在「动作映射」页签里可以逐项指定，指定「自动」才按名字猜。
- **没有声音联动**：动作音效默认关闭，可在设置里打开；开启时遵循 `Config.MotionSound`。
- **窗口能力有限**：桌宠窗口只拿到移动、改尺寸、读光标、鼠标穿透这几个权限，不能关闭自己、不能开机自启。关闭主窗口或托盘里选「退出」会一起结束；从托盘退出时图标先消失，后端继续清理，托盘启用偏好不变。
- **单屏和多显示器**：位置按 `pet-window.json` 恢复，落在可见区域外就挪回主显示器右下角。125% / 150% 缩放和负坐标副屏的手动冒烟还在补。
- **透明区域穿透**：每 50 ms 读一次光标下的像素 alpha 决定是否穿透；拖拽期间强制不穿透。切换模型时会等待旧窗口命令完成，再按新设置重新同步穿透状态；命令失败后在后续轮询重试。没有设置 `premultipliedAlpha` 的模型可能边缘发暗。
- **性能**：30 fps 上限，窗口隐藏时停 ticker。模型很重时（多张大纹理）拖动会掉帧。
