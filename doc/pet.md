# 桌宠

**简体中文** | [繁體中文](./pet.zh-TW.md) | [English](./pet.en.md)

返回 [文档目录](./README.md)。

桌宠是常驻在桌面上的 Live2D 角色：它不参与对话，只是从同一条会话日志中读取**已经定稿**的助手回复，根据关键词判断情绪，然后用固定的场景表来播放动作和表情。它不改写系统提示词，不要求模型输出情绪标签，也不会给模型增加额外的请求。

## 1. 功能简介

- **独立小窗口**：透明、无边框、置顶、不在任务栏显示、不可缩放。默认尺寸为 300×360，模型加载后会根据模型画布尺寸及缩放比例自动调整。
- **只读会话**：每 1 秒（说话时每 250ms）轮询 `GET /api/pet/feed`，获取序号 (`seq`) 之后的新回复。不会回放历史回复，刚打开时也不会连续播放已有的会话内容。
- **状态流处理**：仅对助手已定稿的回复进行情绪匹配，正在流式输出的片段不参与。
- **设置共享**：缩放、间隔、情绪冷却、表情保持、动作映射、关键词字典均在“设置 → 桌宠”中配置，保存后立即生效，无需重启。
- **权限边界**：不弹气泡，不主动对话，不向模型发送额外请求。

## 2. Cubism Core 安装

Core 是 Live2D 的运行时，需自行从 Live2D 官网下载并同意协议。

必须使用 **Cubism 5 SDK for Web R5** (`CubismSdkForWeb-5-r.5.zip`)。为确保安全，导入时会严格校验哈希值（`67064a7fb1812cf502f5c4a03bfe12cc638c75a621bb4acf06bb28763df06ba0`），且仅接受特定的核心 JS 文件与许可文件。

1. 在“设置 → 桌宠 → Cubism Core”点击官网链接下载 R5 zip 包。
2. 勾选协议确认后方可导入。
3. 填入绝对路径进行导入。

## 3. 模型导入

模型**不随应用分发**。支持导入目录或 ZIP 包，系统会自动解析 `.model3.json` 并只复制必要资源，同时校验文件类型与大小。重复导入不会占用额外空间。

模型没有 `HitAreas` 时，点击分区比例可手动调整。窗口会自动裁剪至模型人物的不透明区域，而非画布大小，保证在不同模型间显示效果一致。

## 4. 场景触发

场景由“动作组合 + 表情”构成。

- **解析逻辑**：优先使用模型内置的动作映射，无法匹配时 fallback 到程序化参数轨道。
- **触发机制**：涵盖首次加载、闲置待机、各种交互（点击头/脸/身、悬停、拖拽、双击）、语音播报（口型同步）、定时问候、睡眠等。
- **规则**：新场景优先级需 ≥ 当前主场景才会被执行。情绪场景有冷却时间（`EmotionCooldownSeconds`）。
- **睡眠**：长时间无交互会进入睡眠，仅可通过点击唤醒。

## 5. 情绪关键词字典

“设置 → 桌宠 → 情绪字典”定义四种情绪的触发规则。

- **匹配策略**：支持预处理（去 Markdown）、按长度降序匹配、否定词前缀过滤（如“不开心”不会误判为“开心”）。
- **得分**：基于关键词权重（1-5）计算得分，主分最高者胜出。若主分低于 `MinWeight` 或未命中，则不触发。

## 6. 许可与合规

- **Live2D 协议**：Core 遵循 Live2D 商业许可，需用户本地同意；Framework 遵循 Open Software License，随包分发。

## 7. 已知限制

- **口型同步**：无法获取 TTS 实时音素，使用随机的张合包络模拟。
- **程序化动作兜底**：部分模型缺乏标准动作组，需手动调校或由模型关键帧兜底。
- **系统联动**：桌宠窗口移动、改大小、读光标与滑鼠穿透由系统授权，但无法控制应用自启或关闭。
- **透明度**：使用 Alpha 通道决定穿透区域，未启用 `premultipliedAlpha` 的模型可能边缘有暗边。
- **性能**：上限 30 fps，隐藏时暂停计算；重型模型拖拽时可能掉帧。
