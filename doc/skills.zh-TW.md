# Skills

[简体中文](./skills.md) | **繁體中文** | [English](./skills.en.md)

返回 [文件目錄](./README.zh-TW.md)。

Skill 是一份 `SKILL.md`，內容包括名稱、一行描述和具體步驟。放入工作區後，技能清單會出現在模型的系統提示中。

## 檔案格式

位置：`<workspace>/skills/<技能 ID>/SKILL.md`

```markdown
---
name: 程式碼審查
description: 審查一次程式碼變更並指出風險
---
在這裡填寫助手應遵循的步驟。
```

- 第一行必須是 `---`，直到下一個 `---` 之間都是標頭。`name` 與 `description` 必填，其餘鍵會忽略。
- 技能 ID 就是資料夾名稱，只能使用小寫字母、數字、點、底線和連字號，且必須以字母或數字開頭。
- 描述必須是單行，超過 200 個字會被截斷。最多載入 50 個技能。
- 格式不正確的技能會被略過，頁面會顯示警告，但不會中斷程式。

## 在頁面上管理

在「設定 → 技能」頁可以：

- **上傳**：選擇 `SKILL.md`，或上傳根目錄含有 `SKILL.md` 的技能資料夾 `.zip`。
- **建立**：填寫技能 ID、名稱、描述和說明。
- **啟用 / 停用**：停用的技能不會被載入。開關儲存在設定中，替換技能檔案不會暗中重新啟用它。
- **刪除**。
- 沒有編輯功能。技能文字屬於作者，需要修改時請重新上傳。

新增或移除技能後，下一輪就會生效，不需重啟消費者。

## 注入內容

每輪開始前，系統提示會加入以下格式的清單：

```
Available skills (load one with the skill tool before using it):
- <技能 ID> — <名稱>: <描述>
```

沒有技能時不會注入這段內容。

## 已知邊界

清單文字要求模型使用技能前先透過 skill 工具載入，但目前程式碼沒有找到註冊該工具的地方。因此模型目前只能看到 ID、名稱與描述，無法讀取步驟正文。這部分仍待補充。
