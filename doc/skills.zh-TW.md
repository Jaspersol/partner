# Skills

[简体中文](./skills.md) | **繁體中文** | [English](./skills.en.md)

返回 [文件目錄](./README.zh-TW.md)。

一個技能就是一份 `SKILL.md`：名稱、一句話描述、具體步驟。放進工作區後，技能清單會出現在模型的系統提示裡。

## 檔案格式

位置：`<workspace>/skills/<技能 ID>/SKILL.md`

```markdown
---
name: 程式碼審查
description: 審查一次程式碼變更，指出風險
---
這裡寫助手照著做的步驟。
```

- 第一行必須是 `---`，到下一個 `---` 為止是標頭。`name` 和 `description` 必填，其他鍵忽略。
- 技能 ID 即資料夾名稱：小寫字母、數字、點、底線、連字號，以字母或數字開頭。
- 描述是單行，超過 200 字會截斷。最多載入 50 個技能。
- 格式不對的技能會被略過，並在頁面上給出警告，不會中斷。

## 在頁面上管理

側邊欄 **技能** 頁：

- **上傳**：選一個 `SKILL.md`，或把技能資料夾壓成 `.zip`（`SKILL.md` 放在根目錄）。
- **建立**：填技能 ID、名稱、描述、說明四項。
- **啟用 / 停用**：停用的技能不會被載入。開關存在設定裡，替換技能檔案不會把它悄悄打開。
- **刪除**。
- 沒有編輯。技能內容屬於作者，要改就重新上傳。

增刪技能後下一輪生效，不需要重啟消費者。

## 注入什麼

每輪開始前，系統提示裡加入一段清單：

```
Available skills (load one with the skill tool before using it):
- <技能 ID> — <名稱>: <描述>
```

沒有技能時不注入。

## 已知邊界

清單的提示語要求模型先用 skill 工具載入技能再使用，但目前程式碼裡沒有找到註冊這個工具的地方。也就是說，模型目前只看得到 ID、名稱和描述，讀不到步驟正文。待補充。
