# Skills

**简体中文** | [繁體中文](./skills.zh-TW.md) | [English](./skills.en.md)

返回 [文档目录](./README.md)。

Skill 是一份 `SKILL.md` 文件，包含名称、一行描述和执行步骤。把它放进工作区后，技能条目会显示在模型的系统提示中。

## 文件格式

位置：`<workspace>/skills/<技能 ID>/SKILL.md`

```markdown
---
name: 代码评审
description: 审查一次代码改动并指出风险
---
这里填写助手应遵循的步骤。
```

- 文件第一行必须是 `---`，直到下一个 `---` 之间都是头部内容。`name` 和 `description` 必须存在，其他键会被忽略。
- 技能 ID 就是文件夹名称，只能由小写字母、数字、点、下划线和连字符组成，并且必须以字母或数字开头。
- `description` 必须是单行，超过 200 个字符会被截断。最多加载 50 个技能。
- 格式错误的技能会被跳过，页面会显示警告，但不会导致程序中断。

## 页面管理

在“设置 → 技能”中可以：

- **上传**：选择一个 `SKILL.md`，或上传包含根目录 `SKILL.md` 的技能文件夹 `.zip`。
- **创建**：填写技能 ID、名称、描述和说明。
- **启用 / 停用**：停用的技能不会加载。开关保存在设置中，替换文件不会偷偷重新启用技能。
- **删除**。
- 技能内容没有编辑功能；内容属于作者，需要修改时重新上传。

增加或移除技能后，下一轮即可生效，不必重启消费者。

## 注入内容

每轮开始前，系统提示会加入以下形式的列表：

```
Available skills (load one with the skill tool before using it):
- <技能 ID> — <名称>: <描述>
```

没有技能时不会注入这段内容。
