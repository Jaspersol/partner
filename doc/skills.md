# Skills

**简体中文** | [繁體中文](./skills.zh-TW.md) | [English](./skills.en.md)

返回 [文档目录](./README.md)。

一个技能就是一份 `SKILL.md`：名称、一句话描述、具体步骤。放进工作区后，技能列表会出现在模型的系统提示里。

## 文件格式

位置：`<workspace>/skills/<技能 ID>/SKILL.md`

```markdown
---
name: 代码评审
description: 审查一次代码改动，指出风险
---
这里写助手照着做的步骤。
```

- 第一行必须是 `---`，到下一个 `---` 为止是头部。`name` 和 `description` 必填，其他键忽略。
- 技能 ID 即文件夹名：小写字母、数字、点、下划线、连字符，以字母或数字开头。
- 描述是单行，超过 200 字会截断。最多加载 50 个技能。
- 格式不对的技能会被跳过，并在页面上给出警告，不会报错中断。

## 在页面上管理

侧边栏 **技能** 页：

- **上传**：选一个 `SKILL.md`，或把技能文件夹压成 `.zip`（`SKILL.md` 放在根目录）。
- **创建**：填技能 ID、名称、描述、说明四项。
- **启用 / 停用**：停用的技能不会被加载。开关存在设置里，替换技能文件不会把它悄悄打开。
- **删除**。
- 没有编辑。技能内容归作者所有，要改就重新上传。

增删技能后下一轮生效，不需要重启消费者。

## 注入什么

每轮开始前，系统提示里加入一段列表：

```
Available skills (load one with the skill tool before using it):
- <技能 ID> — <名称>: <描述>
```

没有技能时不注入。

## 已知边界
