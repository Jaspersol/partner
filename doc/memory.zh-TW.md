# 記憶

[简体中文](./memory.md) | **繁體中文** | [English](./memory.en.md)

返回 [文件目錄](./README.zh-TW.md)。

你說過「我用的是公司內網帳號 alice」，下次換個說法問，它想得起來。記憶存在本機 SQLite，每一條都能看、能改、能刪。

## 怎麼運作

| 環節 | 做法 |
|---|---|
| 寫入 | 每輪對話結束後自動提煉。桌面任務只收成功執行的動作結果 |
| 召回 | 每輪開始前檢索相關記憶，注入系統提示，上限約 5000 token；超出會標明「已截斷」 |
| 時效 | 注入的每條帶層級和時間，如 `[established, 10 天前]`，並提示模型以你現在說的為準 |
| 中文 | 另外建了 bigram 全文索引，中文檢索不靠全表掃描 |

子 agent 的回報不進記憶。

## 四個層級

介面上顯示為：**剛記下 / 經歷 / 事實 / 做法**。

- 新寫入的同層記錄和舊的衝突時，舊的標為失效並記下被誰取代，但不刪除。
- 三個月沒被召回的記錄降一級，最後由定期清理移除。
- 層級可以在記憶頁手動改。「這是我依賴的事實」只有你能判斷。

## 在記憶頁能做什麼

- 檢視全部記錄，包括已失效的，以及「什麼取代了它」「上次什麼時候用過」。
- 依層篩選，每層顯示數量。
- **固定**：固定的記錄不會被自動降級或清理，但仍可以被新的同層記錄更正。
- **新建**：手寫一條記憶，預設落在「事實」層，長度 4–400 字。
- 刪除單條記錄。

## 和對話刪除的關係

刪除或撤回一段對話時，由這段對話提煉出的記憶一起刪除。手寫的記憶不屬於任何一輪對話，不會跟著刪。

## 維護與設定

- 宿主每天跑一次維護：升級、降級、清理過期、壓縮。單次失敗只記錄，下次重試。
- `memory.embeddings`：本機 n-gram 雜湊向量，預設關閉，無外部相依。改動在下次開啟記憶庫時生效。

## 儲存

`<workspace>/memory/memory.db`。這是唯一儲存，刪除即遺失。
