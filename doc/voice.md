# 语音功能

**简体中文** | [繁體中文](./voice.zh-TW.md) | [English](./voice.en.md)

返回 [文档目录](./README.md)。

说一句话，它进队列、跑一个回合、把回复读出来。语音和打字走同一条队列，按到达顺序执行。

## 链路

```
麦克风 → 停顿断句 → ASR → 队列 → 回合 → 会话
                                         ↓
扬声器 ← 顺序播放 ← TTS ← 切句 ← 新的助手回复
```

- 输入和输出各自启动、各自报错。麦克风打不开，不影响朗读。
- 只朗读启动后新出现的回复，不会一开机就读历史。
- “朗读时不听麦克风”建议打开，避免把助手自己的声音当成你在说话。
- “说话时打断助手”：助手在说话时你开口约半秒就让它停下。没有回声消除，建议只在戴耳机时打开。

## 两种接法

| 接法 | 适合 | 配置位置 |
|---|---|---|
| 本地引擎 | 不想自己部署服务 | 设置 → 本地引擎，点“下载” |
| 外部服务 | 已有 ASR/TTS 服务 | 设置 → 语音输入 / 语音输出，填服务地址 |

## 本地引擎：分体下载

安装包只带两个小服务脚本。运行时和模型不打包，按引擎单独下载：

| 引擎 | 用途 | 占用 | 体积 | 默认端口 |
|---|---|---|---|---|
| TTS（Qwen3-TTS 1.7B GGUF） | 朗读 | 显存约 1.9 GB | 约 3.0 GB | 45102 |
| KWS + ASR（sherpa-onnx + SenseVoice） | 唤醒 + 识别 | 内存，纯 CPU | 约 380 MB | 45103 |

- 只要识别，就只下 KWS + ASR，不需要显卡。
- 下载可续传；有 SHA-256 就校验；服务端给了长度就核对，截断不算成功。
- 连接中途断掉会自动重试三次（从已下载的部分继续）；60 秒收不到数据也按断线处理，不用重新点下载。
- 设置页“检测”按磁盘文件判断是否就绪，并列出缺了什么。也可以手动指定已有的引擎目录。
- 默认路径存为相对应用目录，应用搬家或重装不用改设置。
- 关掉开关 = 结束引擎进程（整棵进程树），显存和内存全部归还。

下载地址可用环境变量覆盖：`PARTNER_ENGINE_TTS_URL`、`PARTNER_ENGINE_KWS_URL`（以及对应的 `_SHA256`）。
一个引擎可以由多个压缩包组成（GitHub 单个 release 资产上限 2 GiB，TTS 装不进一个），应用按顺序下载、逐个解压到同一目录。
发布包用 `scripts/pack-engines.ps1` 从本机 `engines/` 生成：模型不进 git，脚本负责重打可搬运的运行时、切包、算 SHA-256，并打印要填进 `EnginePackage.cs` 的地址表。
每个包里都有 `NOTICE/`：上游来源、改动声明、完整许可文本；这些包的许可与 MIT 无关，见 [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md)。

开发机可以用脚本装进仓库的 `engines/`，设置页能直接检测到：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/install-engines.ps1              # 两个都装
powershell -ExecutionPolicy Bypass -File scripts/install-engines.ps1 -Engine kws  # 只装识别
powershell -ExecutionPolicy Bypass -File scripts/install-engines.ps1 -Engine tts  # 只装朗读
```

TTS 从 wav/mp3 克隆音色时需要 `ffmpeg` 在 PATH 上；用自带的音色锚点则不需要。

## 唤醒

开启 KWS 引擎后，语音输入进入唤醒模式：麦克风一直在采，但听到唤醒词之前不做识别。

- 唤醒词在“设置 → 语音输入 → 唤醒”里填，多个用逗号分隔；留空则沿用引擎里现有的词。
- “唤醒后等你开口”默认 5000 ms，留给你想要说什么；一开口就改按“停顿多久算说完”断句。
- 可开“唤醒时叮一声”，需要同时开启语音输出。
- 唤醒词后紧跟的话不会被截掉。

## 改设置的影响

改输入、输出、ASR、TTS 任一项会重启语音宿主（重开设备）。只改模型不会，避免打断正在进行的识别。

## 已知边界

- 完整回路的自动化测试用的是合成声源，没有在真麦克风上跑完整句。
- KWS 官方包只有 chunk-16，唤醒延迟约 320 ms。
