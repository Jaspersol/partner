# MCP

**简体中文** | [繁體中文](./mcp.zh-TW.md) | [English](./mcp.en.md)

返回 [文档目录](./README.md)。

通过 stdio 接入 MCP 服务器，并把服务器提供的工具交给主 agent 使用。此功能默认关闭，开启后会启动对应的子进程。

## 配置

进入“设置 → MCP”：

1. 打开 MCP 总开关。
2. 添加服务器，填写名称、启动命令和启动参数（每行一个）；也可以填写工作目录和最长等待时间，默认 30 秒。名称和启动命令是必填项。
   最长等待只限制工具调用，不限制进程启动。比如冷启动的 `dotnet` 进程可能需要 300 毫秒以上，这不会被判定为失败；握手另有 30 秒预算。
   启动命令只写名称时，程序只会从系统 PATH 查找；否则请填写完整路径。
3. 保存设置。消费者启动服务器后，会把各服务器 `tools/list` 返回的结果注册到工具表中。

## 工具命名

工具名称会加上 `mcp_{服务器名}_` 前缀，因此不同服务器即使提供同名工具，也不会互相覆盖。

## 审批

- MCP 工具不使用输入区的审批档位，而是由自己的允许清单控制。
- 默认每次调用都要询问。只有在页面上为某个服务器打开“免审批”后，该服务器的工具才会直接运行。
- 启用服务器只代表提供这些工具，并不代表这些工具可以免审批执行。

## 设置变更的影响

| 变更内容 | 结果 |
|---|---|
| 服务器列表 | 重启消费者，并重新启动子进程 |
| 免审批清单 | 不需要重启，下次调用时生效 |
| 其他会触发消费者重建的设置 | MCP 配置未变时复用原有连接和工具描述；关闭 MCP、修改服务器配置或停止消费者时会回收连接 |

## 出错时

某个服务器启动失败不会影响其他服务器，失败原因会记录在消费者状态中。

单个回合最多允许 MCP 工具执行 32 步，普通工具最多 8 步。
