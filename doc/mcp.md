# MCP

**简体中文** | [繁體中文](./mcp.zh-TW.md) | [English](./mcp.en.md)

返回 [文档目录](./README.md)。

接入 stdio 方式的 MCP 服务器，把它们的工具交给主 agent 使用。默认关闭：启用即启动子进程。

## 配置

侧边栏 **MCP** 页：

1. 打开总开关。
2. 添加服务，填名称、启动命令、启动参数（每行一个），可选运行目录和最长等待（默认 30 秒）。名称和启动命令必填。
   启动命令只写名字时只在系统 PATH 里查找，其他情况写完整路径。
3. 保存。消费者启动时拉起各服务器，并把 `tools/list` 的结果注册进工具表。

## 工具命名

工具名加前缀 `mcp_{服务器名}_`，两台服务器有同名工具也不会互相覆盖。

## 审批

- MCP 工具不受输入区审批挡位控制，有自己的允许清单。
- 默认每次调用都询问。在页面上打开某个服务的“免审批”后，这个服务的工具才直接执行。
- 启用一个服务器只决定“提供哪些工具”，不决定“哪些可以直接动”。

## 改设置的影响

| 改了什么 | 效果 |
|---|---|
| 服务器列表 | 重启消费者，子进程重新拉起 |
| 免审批清单 | 不重启，下一次调用即生效 |

## 出错时

某个服务器起不来不影响其他服务器，失败原因会被记录在消费者状态里。

一轮里 MCP 工具的步数上限是 32，普通工具是 8。
