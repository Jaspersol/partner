# 子 agent

**简体中文** | [繁體中文](./sub-agents.zh-TW.md) | [English](./sub-agents.en.md)

返回 [文档目录](./README.md)。

主 agent 只对话和派活。点窗口、读文件这类耗时的活交给子 agent 在后台做，做完把结果作为一条新输入回报，主 agent 再转述给你。

## 场景

场景是固定的两项，每个场景最多一个子 agent：

| 场景 | 子 agent 的工具 | 开关 | 谁来占用 |
|---|---|---|---|
| `desktop` 桌面操控 | `desktop_*` | `desktop.enabled` | 内置“桌面操控”子 agent，不可删 |
| `file-read` 读取文件 | `file_list`、`file_read`（只读） | `files.enabled`（默认关）+ 目录白名单 | 用户自己新增 |

- 没人占用的场景由主 agent 自己执行。例如开了读文件但没建读文件子 agent，`file_*` 工具就给主 agent。
- 桌面例外：桌面工具从不给主 agent。开启桌面就必须有启用的桌面子 agent，保存时会校验。

## 派活与回报

- 主 agent 有三个工具：`agent_delegate`（立即返回）、`agent_job_status`、`agent_job_cancel`。
- 任务在后台跑，不占主对话。结束后汇报进入同一条队列，主 agent 起新的一轮来转述。
- 每个任务有自己的会话日志（`agents/<agent>/job-*/session/`）；每个 agent 只保留最近 30 个任务。截图和读到的文件内容不进主会话，也不进记忆。
- 一个子 agent 同时只跑一个任务。同一目标刚失败，10 分钟内不能原样再派。
- 进程崩溃后，没结束的任务会在下次启动时补一条“已中断”的汇报。

## 重试与失败

- 每个任务最多跑 `maxRounds` 轮，默认 5（可调 1–10）。总时限 15 分钟。
- 成败由子 agent 调用 `task_report` 判定：成功要带证据，失败要带错误。没调用就算失败。
- 审批被拒、治理拒绝、取消、超时等终止类失败不重试。其余失败重试前，会把上一轮已执行的动作告诉子 agent，要求先看现状。
- 全部失败时，主 agent 收到原因类别、最后一次错误和逐轮记录，并被要求如实转告，不能说成功。

## 提示词与模型

在侧边栏 **agent** 页编辑：

- 主 agent 和每个子 agent 都有可编辑的提示词。没改过就用内置默认，升级后自动拿到新默认。
- 末尾自动生成的“可委派场景”“汇报方式”两段不可编辑。
- 改提示词不重启消费者，下一轮生效。
- 子 agent 的模型默认跟随主模型，也可以单独配，比如桌面子 agent 用视觉模型。

## 读文件的边界

- 路径必须在 `files.roots` 内。`..` 穿越和指向目录外的链接都拒绝。
- 只读文本，按段读取，单段默认 12000、上限 40000 字符；二进制和超过 8 MB 的文件拒绝。
- 目录内也不读 `.env*`、`*.pem`、`*.key`、`*.pfx` 等密钥文件，以及整个工作区。
- 读到的内容会进模型上下文，白名单别配得太宽。
