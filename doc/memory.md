# 记忆

**简体中文** | [繁體中文](./memory.zh-TW.md) | [English](./memory.en.md)

返回 [文档目录](./README.md)。

你说过“我用的是公司内网账号 alice”，下次换个说法问，它能想起来。记忆存在本地 SQLite，每一条都能看、能改、能删。

## 怎么工作

| 环节 | 做法 |
|---|---|
| 写入 | 每轮对话结束后自动提炼。桌面任务只收成功执行的动作结果 |
| 召回 | 每轮开始前检索相关记忆，注入系统提示，上限约 5000 token；超出会标明“已截断” |
| 时效 | 注入的每条带层级和时间，如 `[established, 10 天前]`，并提示模型以你现在说的为准 |
| 中文 | 单独建了 bigram 全文索引，中文检索不靠全表扫描 |

子 agent 的汇报不进记忆。

## 四个层级

界面上显示为：**刚记下 / 经历 / 事实 / 做法**。

- 新写入的同层记录和旧的冲突时，旧的标为失效并记下被谁替换，但不删除。
- 三个月没被召回的记录降一级，最后由定期清理移除。
- 层级可以在记忆页手动改。“这是我依赖的事实”只有你能判断。

## 在记忆页能做什么

- 查看全部记录，包括已失效的，以及“什么替换了它”“上次什么时候用过”。
- 按层筛选，每层显示计数。
- **固定**：固定的记录不会被自动降级或清理，但仍可以被新的同层记录纠正。
- **新建**：手写一条记忆，默认落在“事实”层，长度 4–400 字。
- 删除单条记录。

## 和对话删除的关系

删除或撤回一段对话时，由这段对话提炼出的记忆一起删除。手写的记忆不属于任何一轮对话，不会跟着删。

## 维护与设置

- 宿主每天跑一次维护：升级、降级、清理过期、压缩。单次失败只记日志，下次重试。
- `memory.embeddings`：本地 n-gram 哈希向量，默认关闭，无外部依赖。改动在下次打开记忆库时生效。

## 存储

`<workspace>/memory/memory.db`。这是唯一存储，删除即丢失。
