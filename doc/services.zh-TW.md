# 對外服務（Memory Service）

[简体中文](./services.md) | **繁體中文** | [English](./services.en.md)

返回 [文件目錄](./README.zh-TW.md)。

「對外服務」用於把外部 agent 和插件接入 Partner：讓屬於你的 Partner 對接任何兼容大模型的平台，比如遊戲 AI mod、編輯器/瀏覽器插件或其他 agent 框架。應用可托管多個服務，每個佔用獨立 `127.0.0.1` 連接埠，透傳 OpenAI 或 Anthropic 模型。它會在請求中注入主記憶召回，可選前置自定義提示詞，並定期將交互總結寫回主記憶庫。

## 應用場景

遊戲 mod、插件等通常自行連接模型，無法感知你的身份或歷史上下文。將它們的模型地址指向對外服務，即可接入 Partner 的記憶系統；其交互內容也會自動匯總至主記憶，方便你在對話中隨時查詢。

接入前提：
- 程式支援自定義 Base URL、API Key 和模型名（多數支援 OpenAI/Anthropic 介面的 mod 均可）。
- 與 Partner 運行於同一台機器（服務僅監聽 `127.0.0.1`）。
- 協定匹配（上游 OpenAI 選 `openai`，Anthropic 選 `anthropic`）。

接入步驟：
1. 在「對外服務」頁添加服務並複製令牌。
2. 在 mod/插件中設定：
   - **Base URL**：`http://127.0.0.1:<連接埠>/v1`
   - **API Key**：服務令牌
   - **模型名**：配置指定的模型名稱

## 核心機制

- **反向代理**：認證替換、模型名映射，其餘參數（Tools, Stream, Response Format 等）原樣透傳。
- **無狀態**：服務不保存會話，客戶端負責維護歷史。
- **記憶增強**：每次請求自動檢索主記憶，注入到 user 訊息前；可選前置自定義提示詞。
- **自動總結**：定期將窗口期交互總結為一句話，寫入主記憶，標記來源 `service:<id>`。
- **安全隔離**：僅監聽 `127.0.0.1`，拒絕未經配置的模型名請求。

召回針對最後一條帶文字的 user 訊息進行，不支援 cross-service 召回。服務總結任務在交互結束後異步寫入。

## 介面管理

側邊欄「對外服務」頁：
- 創建服務，記錄明文令牌（僅展示一次）。
- 即時監控：運行狀態、請求量、待總結輪次及最近寫入記憶。
- 卡片操作：立即總結、輪換令牌、刪除（可選同時清理該服務記錄的記憶）。
- 配置熱更新：修改連接埠或協定需重啟服務。

## 關鍵參數

| 字段 | 說明 |
|---|---|
| 名稱 | 來源標籤，摘要中顯示 |
| 協定 | 必須與上游協定嚴格一致，不處理協定轉換 |
| 上下文長度 | 預設繼承主模型 |
| 召回/總結 | 可按需開啟或關閉，配置 token 預算與總結週期 |
| 上游設定 | 可自定義 baseUrl、模型名、API Key 等 |

## 總結與超時控制

- 請求在 headers 到達前有超時限制（繼承主模型或自定義設定）；回應流傳輸不限時。流式長回覆請開啟 `stream: true`。
- 上游返回的限流及重試頭（如 `retry-after`, `x-ratelimit-*`）會原樣透傳給 SDK，方便客戶端重試。

## 記憶刪除與安全

> **服務記憶會寫入主庫，刪除對話不會級聯刪除。**

在「服務」頁刪除服務時勾選「同時刪除它寫入的記憶」即可徹底清除。
*安全建議*：因外部內容會被總結寫進主記憶，存在間接提示注入風險，僅允許受信任的客戶端訪問服務連接埠，並定期審查摘要。關閉「總結」開關可停止寫入，已存記憶需手動刪除。
