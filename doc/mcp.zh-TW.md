# MCP

[简体中文](./mcp.md) | **繁體中文** | [English](./mcp.en.md)

返回 [文件目錄](./README.zh-TW.md)。

透過 stdio 方式接入 MCP 伺服器，讓主 agent 使用伺服器提供的工具。功能預設關閉，啟用時會啟動子行程。

## 設定

前往「設定 → MCP」：

1. 開啟總開關。
2. 新增伺服器，填入名稱、啟動指令和啟動參數（每行一個），也可指定執行目錄與最長等待時間，預設為 30 秒。名稱與啟動指令必填。
   最長等待只約束工具呼叫，不約束啟動。冷啟動的 `dotnet` 行程可能需要 300 毫秒以上，這不會被視為失敗；握手有另外 30 秒的預算。
   啟動指令若只有名稱，程式只會在系統 PATH 中尋找；其他情況請填完整路徑。
3. 儲存。消費者啟動時會帶起各伺服器，並把 `tools/list` 的結果註冊到工具表。

## 工具命名

工具名稱會加上前綴 `mcp_{伺服器名}_`，因此不同伺服器的同名工具也不會相互覆蓋。

## 審批

- MCP 工具不受輸入區審批檔位控制，而是使用自己的允許清單。
- 預設每次呼叫都會詢問。只有在頁面為某個伺服器啟用「免審批」後，該伺服器的工具才會直接執行。
- 啟用伺服器只決定提供哪些工具，不代表這些工具都能免審批執行。

## 設定變更的影響

| 變更 | 效果 |
|---|---|
| 伺服器清單 | 重啟消費者，並重新啟動子行程 |
| 免審批清單 | 不重啟，下次呼叫立即套用 |
| 其他需要重建消費者的設定 | MCP 設定沒有改變時沿用現有連線和工具描述；關閉 MCP、修改伺服器設定或停止消費者時回收連線 |

## 發生錯誤時

單一伺服器啟動失敗不會影響其他伺服器，錯誤原因會記錄在消費者狀態中。

每一輪 MCP 工具最多執行 32 步，一般工具最多 8 步。
