# MCP

[简体中文](./mcp.md) | **繁體中文** | [English](./mcp.en.md)

返回 [文件目錄](./README.zh-TW.md)。

接入 stdio 方式的 MCP 伺服器，把它們的工具交給主 agent 使用。預設關閉：啟用即啟動子行程。

## 設定

側邊欄 **MCP** 頁：

1. 開啟總開關。
2. 新增服務，填名稱、啟動指令、啟動參數（每行一個），可選執行目錄和最長等待（預設 30 秒）。名稱和啟動指令必填。
   啟動指令只寫名稱時只在系統 PATH 裡尋找，其他情況寫完整路徑。
3. 儲存。消費者啟動時帶起各伺服器，並把 `tools/list` 的結果註冊進工具表。

## 工具命名

工具名加上前綴 `mcp_{伺服器名}_`，兩台伺服器有同名工具也不會互相覆蓋。

## 審批

- MCP 工具不受輸入區審批檔位控制，有自己的允許清單。
- 預設每次呼叫都詢問。在頁面上開啟某個服務的「免審批」後，這個服務的工具才直接執行。
- 啟用一個伺服器只決定「提供哪些工具」，不決定「哪些可以直接動」。

## 改設定的影響

| 改了什麼 | 效果 |
|---|---|
| 伺服器清單 | 重啟消費者，子行程重新帶起 |
| 免審批清單 | 不重啟，下一次呼叫即生效 |

## 出錯時

某個伺服器起不來不影響其他伺服器，失敗原因會記錄在消費者狀態裡。

一輪裡 MCP 工具的步數上限是 32，一般工具是 8。
