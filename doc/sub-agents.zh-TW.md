# 子 agent

[简体中文](./sub-agents.md) | **繁體中文** | [English](./sub-agents.en.md)

返回 [文件目錄](./README.zh-TW.md)。

主 agent 只對話和派工。點視窗、讀檔案這類耗時的工作交給子 agent 在背景做，做完把結果當成一條新輸入回報，主 agent 再轉述給你。

## 場景

場景固定兩項，每個場景最多一個子 agent：

| 場景 | 子 agent 的工具 | 開關 | 由誰佔用 |
|---|---|---|---|
| `desktop` 桌面操控 | `desktop_*` | `desktop.enabled` | 內建「桌面操控」子 agent，不可刪 |
| `file-read` 讀取檔案 | `file_list`、`file_read`（唯讀） | `files.enabled`（預設關）+ 目錄白名單 | 使用者自行新增 |

- 沒人佔用的場景由主 agent 自己執行。例如開了讀檔但沒建讀檔子 agent，`file_*` 工具就給主 agent。
- 桌面例外：桌面工具從不給主 agent。開啟桌面就必須有啟用的桌面子 agent，儲存時會檢查。

## 派工與回報

- 主 agent 有三個工具：`agent_delegate`（立即返回）、`agent_job_status`、`agent_job_cancel`。
- 任務在背景跑，不佔主對話。結束後回報進入同一條佇列，主 agent 開新的一輪來轉述。
- 每個任務有自己的工作階段記錄（`agents/<agent>/job-*/session/`）；每個 agent 只保留最近 30 個任務。截圖和讀到的檔案內容不進主工作階段，也不進記憶。
- 一個子 agent 同時只跑一個任務。同一目標剛失敗，10 分鐘內不能原樣再派。
- 行程當掉後，沒結束的任務會在下次啟動時補一條「已中斷」的回報。

## 重試與失敗

- 每個任務最多跑 `maxRounds` 輪，預設 5（可調 1–10）。總時限 15 分鐘。
- 成敗由子 agent 呼叫 `task_report` 判定：成功要帶證據，失敗要帶錯誤。沒呼叫就算失敗。
- 審批被拒、治理拒絕、取消、逾時等終止類失敗不重試。其餘失敗重試前，會把上一輪已執行的動作告訴子 agent，要求先看現狀。
- 全部失敗時，主 agent 收到原因類別、最後一次錯誤和逐輪記錄，並被要求如實轉告，不能說成功。

## 提示詞與模型

在側邊欄 **agent** 頁編輯：

- 主 agent 和每個子 agent 都有可編輯的提示詞。沒改過就用內建預設，升級後自動拿到新預設。
- 結尾自動產生的「可委派場景」「回報方式」兩段不可編輯。
- 改提示詞不重啟消費者，下一輪生效。
- 子 agent 的模型預設跟隨主模型，也可以單獨設定，例如桌面子 agent 用視覺模型。

## 讀檔的邊界

- 路徑必須在 `files.roots` 內。`..` 穿越和指向目錄外的連結都拒絕。
- 只讀文字，分段讀取，單段預設 12000、上限 40000 字元；二進位檔和超過 8 MB 的檔案拒絕。
- 目錄內也不讀 `.env*`、`*.pem`、`*.key`、`*.pfx` 等金鑰檔，以及整個工作區。
- 讀到的內容會進模型上下文，白名單別設得太寬。
