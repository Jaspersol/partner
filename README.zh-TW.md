# Partner

給電腦加一個能用嘴喊的助手：說一句話，它排隊執行、回你一句語音。

[简体中文](README.md) | **繁體中文** | [English](README.en.md)

Partner 不取代程式開發 agent 或工作 agent。它為現有工作流程加一層語音入口：用語音觸發任務，設定盡量少，語音引擎和模型服務按需分開下載到本機。適合想在 Windows 桌面上「喊一聲就辦事」、又不想折騰一堆服務設定的人。

## 它是什麼 / 不是什麼

| 是 | 不是 |
|---|---|
| Windows 桌面應用程式，語音和文字共用一條輸入佇列 | 程式開發 agent、IDE 外掛，也不取代你現有的工作 agent |
| 連接你自己的 OpenAI 相容模型端點 | 自帶大型模型或雲端服務 |
| 本機語音引擎可選、可單獨下載、可隨時關閉 | 必須先下載 3 GB 模型才能用的安裝包 |

## 核心特點

- **單一工作階段，依日期檢視**：只有一條工作階段，不用新建、切換或管理多個對話；記憶和上下文始終連續。介面依日期呈現，用「年 → 月 → 日」選擇器翻看有對話的日子，預設停在最新一天。
- **語音控制**：喚醒詞開閘，說完自動斷句、辨識、排入佇列；回覆逐句朗讀，播放時暫停收音。
- **一站式簡約設定**：在一個設定頁填好模型位址就能跑。連接埠、啟動 API、權杖注入由桌面殼自動完成；模型名稱和音訊裝置從下拉選單選，不用手打；改完立即生效，不用重新啟動。
- **分體式下載本機引擎**：安裝包只帶兩個小服務腳本。TTS（約 3.0 GB）和喚醒＋辨識（約 380 MB）在「設定 → 本機引擎」裡各自下載，支援續傳和校驗；關閉即結束行程，顯示記憶體與系統記憶體全部歸還。

## 單一工作階段 + 依日期呈現

所有輸入（打字、語音、定時任務、子 agent 回報）都進同一條工作階段記錄，依到達順序執行。

- **日期只是檢視**：記錄不按天拆分，選哪天只決定顯示哪一段。在舊日期下發訊息，仍然附加到記錄末尾。
- **只列有對話的日子**：沒有對話的日期選不到；某天有了第一條訊息會自動出現。
- **依本機日曆劃分**：前端把時區偏移傳給伺服器，「哪一天」以你所在時區為準。
- **跨午夜不跳頁**：午夜前開始的回合還在寫時，介面停在原來那天，閒置後再切到新的一天。

## 快速啟動

### 前置條件

| 項目 | 要求 |
|---|---|
| 系統 | Windows 10 2004 以上 |
| .NET | .NET 8 SDK |
| Node | Node 22 + npm（不要用 pnpm，esbuild 會裝不上） |
| Rust | cargo 1.98+（只有桌面殼需要） |
| WebView2 | Win10+ 內建 |
| 模型 | 一個 OpenAI 相容端點，例如本機 Ollama |

### 安裝與啟動

```bash
npm --prefix ui install          # 第一次
npx --prefix ui tauri dev        # 啟動前端 + 桌面殼，殼會自動帶起 API
```

啟動後在「設定 → 對話模型」填服務位址並選模型。沒設定模型時佇列不會執行，介面會寫明缺什麼。也可以用環境變數：

```bash
export PARTNER_LLM_BASE_URL=http://127.0.0.1:11434/v1
export PARTNER_LLM_MODEL=qwen3
export PARTNER_LLM_API_KEY=...   # 選填
```

### 打包安裝檔

```bash
bash scripts/build-shell.sh      # 發佈 API → 建置前端 → 編譯殼 → 打包 NSIS 安裝檔
```

### 只跑測試

```bash
bash scripts/ci.sh               # 編譯、單元測試、smoke、能力門檻、前端、殼
SKIP_SHELL=1 bash scripts/ci.sh  # 跳過最慢的殼編譯
```

## 常見問題

**一定要下載本機語音引擎嗎？** 不必。文字輸入不依賴語音；語音也可以接你已有的 ASR/TTS 服務位址。

**資料存在哪？** 預設 `%LocalAppData%/Partner/workspace`：工作階段記錄、佇列、記憶庫、設定都在這裡。記憶庫是唯一儲存，刪除即遺失。

**支援 macOS / Linux 嗎？** 不支援。桌面操控和音訊都依賴 Win32 介面。
